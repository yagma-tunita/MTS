# MTS 各角色功能说明

---

## 一、客户（货主 / shipper）

| 功能 | 接口 | 说明 |
|------|------|------|
| 注册 | `POST /shipper/register` | 创建货主账号 |
| 登录 | `POST /auth/login` (role=shipper) | 登录系统 |
| 查看城市列表 | `GET /cities` | 选择出发/目的城市 |
| 查看港口 | `GET /ports?city_id=X` | 查看某城市下的港口 |
| 查看航线 | `GET /shipping-lines` | 查看所有航线 |
| 查看船舶 | `GET /vessels` | 查看所有船舶 |
| 航次推荐 | `GET /voyages/recommend` | 输入起止港+吨数，系统推荐可用航次 |
| 查看船公司 | `GET /shipping-companies` | 查看可选运输服务商 |
| 创建订单 | `POST /orders` | 选航次下单，填货物信息、预计时间 |
| 虚拟支付 | `POST /orders/:id/pay` | 支付订单 |
| 查看订单 | `GET /orders` | 查看自己的订单列表 |
| 订单详情 | `GET /orders/:id` | 查看订单完整信息 |
| 订单跟踪 | `GET /orders/:id/tracking` | 查看预计/计划/实际三段时间线 |
| 修改密码 | `POST /shipper/password/:id` | 修改登录密码 |

---

## 二、船公司（shipping）

| 功能 | 接口 | 说明 |
|------|------|------|
| 登录 | `POST /auth/login` (role=shipping) | 登录系统 |
| 查看订单 | `GET /orders` | 查看所有订单（含货主名、起止港） |
| 订单详情 | `GET /orders/:id` | 查看订单完整信息 |
| 更新订单状态 | `PUT /orders/:id/status` | 已确认→运输中→已完成 |
| 取消订单 | `POST /orders/:id/cancel` | 取消订单释放运力 |
| 航线申请 | `POST /voyages/berthing` | 创建航次靠泊记录（排班） |
| 录入实际时间 | `PUT /berthings/:id/actual-times` | 更新船舶实际到港/离港时间 |
| 查看港口 | `GET /ports` | 查看港口列表和详情 |
| 查看船舶 | `GET /vessels` | 查看自己公司的船舶 |
| 查看航线 | `GET /shipping-lines` | 查看所有航线 |
| 查看通知 | `GET /notifications` | 查看系统通知 |
| 修改密码 | `POST /shipping/password/:id` | 修改登录密码 |
| 报表统计 | `GET /reports/orders` | 订单统计报表 |
| 航次利用率 | `GET /reports/voyage-utilization` | 航次舱位利用率查询 |
| 导出订单 | `GET /export/orders` | 导出订单 Excel |

## 三、管理员（admin）

| 功能 | 接口 | 说明 |
|------|------|------|
| 登录 | `POST /auth/login` (role=admin) | 登录系统 |
| 管理员列表 | `GET /admin/list` | 查看所有管理员 |
| 创建管理员 | `POST /admin/register` | 新建管理员账号 |
| 修改管理员密码 | `POST /admin/password/:id` | 修改指定管理员密码 |
| **货主公司管理** | | |
| 查看货主列表 | `GET /admin/shipper/list` | 查看所有货主公司 |
| 更新货主公司 | `POST /admin/shipper/:id/update` | 修改货主信息（部分字段） |
| 删除货主公司 | `POST /admin/shipper/:id/delete` | 软删除货主账号 |
| **船公司管理** | | |
| 查看船公司列表 | `GET /admin/shipping/list` | 查看所有船公司 |
| 更新船公司 | `POST /admin/shipping/:id/update` | 修改船公司信息（部分字段） |
| 删除船公司 | `POST /admin/shipping/:id/delete` | 软删除船公司账号 |
| **港口管理** | | |
| 创建港口 | `POST /admin/ports` | 新增港口 |
| 更新港口 | `PUT /admin/ports/:id` | 修改港口信息（部分字段） |
| 删除港口 | `DELETE /admin/ports/:id` | 软删除港口 |
| **船舶管理** | | |
| 创建船舶 | `POST /admin/vessels` | 新增船舶（船型、容量、航速） |
| 更新船舶 | `PUT /admin/vessels/:id` | 修改船舶参数（部分字段） |
| 删除船舶 | `DELETE /admin/vessels/:id` | 软删除船舶 |
| **航线管理** | | |
| 创建航线 | `POST /admin/shipping-lines` | 新增航线（港口序列、里程） |
| 更新航线 | `PUT /admin/shipping-lines/:id` | 修改航线信息（部分字段） |
| 删除航线 | `DELETE /admin/shipping-lines/:id` | 软删除航线 |
| **货物管理** | | |
| 货物列表 | `GET /admin/cargo/list` | 查看所有货物的运输记录（含订单信息） |
| **通知管理** | | |
| 发送通知 | `POST /admin/notifications` | 向指定用户发送通知 |
| 查看通知 | `GET /notifications` | 查看系统通知 |

## 四、各角色能力边界

| 操作 | 客户 | 船公司 | 管理员 |
|------|:---:|:-----:|:-----:|
| 注册账号 | ✅ | ✅ (公开注册) | ❌ (需admin创建) |
| 创建订单 | ✅ | ❌ | ❌ |
| 查看所有订单 | 仅自己的 | ✅ | ✅ |
| 更新订单状态 | ❌ | ✅ | ❌ |
| 取消订单 | ❌ | ✅ | ❌ |
| 录入靠泊时间 | ❌ | ✅ | ❌ |
| 管理港口/船舶/航线 | ❌ | ❌ | ✅ |
| 管理账号 | ❌ | ❌ | ✅ |
| 航次推荐 | ✅ | ✅ | ✅ |
